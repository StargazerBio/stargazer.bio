Stargazer

Genomics pipelines in a notebook

Stargazer is an open-source library of bioinformatics tasks, from alignment and germline variant calling to single-cell RNA-seq clustering. Run them, chain them into pipelines and write your own in marimo notebooks, with an AI agent in the terminal beside you.

Log in Read the docs Source on GitHub

Or run it on your own machine:

docker run -p 8080:8080 ghcr.io/stargazerbio/stargazer

Stargazer is alpha software. Don't upload sensitive data, such as identifiable patient data.
